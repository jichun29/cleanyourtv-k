# TCL Smart TV Pro, US (device G05, product G05_4K_US, board C05, MediaTek MT5889 / MT9615)
# Android 11 (Google TV), firmware AR2101, software AR68 (built March 2024), 2.7 GB RAM
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-g05-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-g05-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh, the default is wrong here).
# Live TV app: com.tcl.tv (keep it, it also owns HDMI/antenna playback). Keep com.tcl.tvinput,
# com.tcl.settings, com.tcl.system.server,
# com.tcl.keyhelp, com.tcl.autopair, com.tcl.tcl_bt_rcu_service (remote) and com.tcl.providers.config.
# Unlike the G10, com.tcl.ttvs ships enabled here; it carries TCL's BI analytics service.
#
# Known quirk, read before replacing the launcher (the one report so far where disabling setupwraith
# did NOT stick):
# - With launcherx disabled, com.google.android.tungsten.setupwraith/.RecoveryActivity claims HOME at
#   priority 1 and Home lands on a black, looping recovery screen. Shell cannot disable that component.
#   Disabling the whole setupwraith package worked until a reboot, after which this TV had it back in
#   charge, unlike the MOOR2, QM6K and Chromecast reports where the disable survives.
#   Recover with: pm enable com.google.android.apps.tv.launcherx; pm enable com.google.android.tungsten.setupwraith
# - The launcher half is therefore unverified on the G05: launcher/build-and-install.sh will refuse and
#   roll back while Home resolves to setupwraith (README, Troubleshooting). This list is the debloat half.
#   Contributed by damonearl (PR #73).
