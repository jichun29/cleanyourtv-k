# com.mediatek.tvinputservice.arbitratorservice (tuner/HDMI plumbing),
# com.google.android.apps.mediashell (Chromecast built-in, owner uses it).
#
# QUIRKS ON THIS FIRMWARE:
# - screencap prints "Init wrapper sys mutex successful..." junk to stdout before the PNG, so
#   `adb exec-out screencap -p` is corrupt. Use `screencap -p /sdcard/x.png` + `adb pull` instead.
# - Port 5555 is closed until USB debugging has been toggled/authorised; it opened without a
#   separate Network-debugging switch on this unit. No Wireless-debugging (pairing) menu exists.
# - The uk.co.freeview.* pack (BBC, ITV, Ch4/5, Freeview explore...) ships already disabled on
#   Spain-market units; it is not listed below because `pm list packages -d` already held it.
# - The remote's YouTube and Prime Video buttons are handled by Vestel firmware below Android: the
#   IR driver logs "u4IRKey after convert: 0xffffffff" and no keycode reaches InputDispatcher
#   (getevent shows scancodes 0x129/0x13e, but the IR device's vendor keylayout drops them). With
#   their apps disabled the buttons simply do nothing; no launcher key service can remap them.
# - The TV closes Wi-Fi (and ADB with it) in standby, and `settings put secure
#   enabled_accessibility_services` was found cleared once afterwards: re-check accessibility
#   services after a standby cycle if you rely on one.
