# 各品牌电视开启 ADB 的方法

> 给 AI 和用户参考：不同品牌电视打开 ADB 调试的路径不一样，这里汇总常见机型的操作步骤。
> 不需要部署到 APK 里，仓库里放着随时查。

---

## 小米 / Redmi（MIUI TV / PatchWall）

**路径**：设置 → 账号与安全 → 安全 → ADB 调试 → 开启

**部分老机型**（如 Mi TV 4A）：设置 → 关于 → 产品型号 → 连按 5 次「确定」→ 返回 → 开发者选项 → ADB 调试 → 开启

**注意**：
- 开启后电视会提示「允许这台电脑调试吗」，遥控器按「确定」
- 小米电视默认端口是 **5555**，不用改
- 部分机型需要先登录小米账号才能开开发者选项

---

## 华为 / 荣耀（HarmonyOS / EMUI TV）

**路径**：设置 → 系统 → 开发者选项 → ADB 调试 → 开启

**没有开发者选项时**：设置 → 关于电视 → 版本号 → 连按 7 次「确定」→ 返回上级菜单出现「开发者选项」

**注意**：
- 华为电视 ADB 端口也是 **5555**
- 部分机型需要插网线才能开 ADB（Wi-Fi 下不显示）

---

## TCL / 雷鸟（Android TV / 灵控桌面）

**路径**：设置 → 系统 → 关于 → 版本信息 → 连按「确定」5~7 次 → 返回 → 开发者选项 → USB 调试 → 开启

**注意**：
- TCL 电视 ADB 默认端口 **5555**
- 部分机型（如雷鸟）需要先开「商场模式」才能看到开发者选项

---

## 海信 / VIDAA

**路径**：设置 → 通用设置 → 关于 → 版本号 → 连按「确定」5 次 → 返回 → 开发者模式 → ADB 调试 → 开启

**注意**：
- 海信电视 ADB 端口 **5555**
- 部分海外版 VIDAA 系统不开放 ADB

---

## 创维 / 酷开（酷开系统）

**路径**：设置 → 本机信息 → 更多信息 → 连按「确定」5 次 → 返回 → 开发者选项 → ADB 调试 → 开启

**注意**：
- 酷开系统 ADB 端口 **5555**
- 部分机型需要先在「应用管理」里安装「酷开应用圈」才能看到开发者选项

---

## 康佳（易柚系统）

**路径**：设置 → 系统设置 → 关于本机 → 版本号 → 连按「确定」5 次 → 返回 → 开发者选项 → ADB 调试 → 开启

**注意**：
- 康佳电视 ADB 端口 **5555**
- 部分老机型需要插 U 盘装「康佳管家」才能开

---

## 索尼（Android TV / Google TV）

**路径**：设置 → 系统 → 关于 → 版本号 → 连按「确定」7 次 → 返回 → 开发者选项 → ADB 调试 → 开启

**注意**：
- 索尼电视 ADB 端口 **5555**
- 2021 年后的 Google TV 机型路径略有不同：设置 → 系统 → 关于 → Android TV 操作系统版本 → 连按

---

## LG（webOS）

**webOS 不是 Android，不能用 ADB**，需要用 LG 自己的开发者模式：
- 设置 → 一般 → 关于本机 → 电视信息 → 连按「确定」5 次 → 开发者模式 → 开启
- 然后用 `ares-install` 或 `webOS CLI` 工具，不是 ADB

**本项目不支持 webOS**，只支持 Android TV 系统的电视。

---

## 三星（Tizen）

**Tizen 不是 Android，不能用 ADB**，需要用三星自己的开发者模式：
- 设置 → 支持 → 关于本机 → 软件版本 → 连按「确定」5 次 → 开发者模式 → 开启
- 然后用 `sdb`（Smart Development Bridge）工具，不是 ADB

**本项目不支持 Tizen**，只支持 Android TV 系统的电视。

---

## 通用方法（适用于大多数 Android TV）

如果上面的路径找不到，试试这个：

1. 打开电视的「设置」
2. 找「关于」或「关于本机」
3. 找「版本号」或「产品型号」
4. 用遥控器连按「确定」或「OK」键 **5~7 次**
5. 提示「已进入开发者模式」后返回
6. 找「开发者选项」→「ADB 调试」或「USB 调试」→ 开启

---

## 验证 ADB 是否开启成功

在电脑上（和电视同一局域网）：

```bash
adb connect 电视IP:5555
# 成功会显示：connected to 192.168.x.x:5555
adb devices
# 能看到设备列表里有你的电视
```

如果连接失败：
- 确认电视和电脑在同一局域网（同一个路由器）
- 确认电视的 ADB 调试已开启
- 部分电视需要重启后 ADB 才生效
- 防火墙/路由器 AP 隔离会阻止连接，关掉再试

## 常见问题

**Q：为什么我的电视找不到「开发者选项」？**
A：部分品牌（如 LG webOS、三星 Tizen）不是 Android 系统，不支持 ADB。只有 Android TV 系统的电视才能用本项目的桌面。

**Q：ADB 端口不是 5555 怎么办？**
A：部分机型（如某些海外版）可能用其他端口，在开发者选项里看「ADB 端口号」，连接时用 `adb connect IP:端口号`。

**Q：开启 ADB 后电视变卡了？**
A：ADB 本身不占资源，但如果你装了太多应用或开了太多后台服务，会变卡。建议用本项目的去广告清单停用不需要的系统应用。
