# Known quirks on this firmware:
# - Unlike the Chromecast on Google TV 14, port 5555 is open as soon as USB debugging is on; no pairing.
# - If a VPN app is connected, Settings > Network shows the VPN tunnel address, not the LAN one.
#   Find the box with `nc -z <lan>.x 5555` or `dns-sd -B _adb-tls-connect._tcp local.`.
# - The Wi-Fi network saved during first setup belongs to setupwraith (dumpsys wifi: cname=...setupwraith).
#   Forget and re-join it in Settings before disabling setupwraith, or the network is deleted.
# - As on the Chromecast, setupwraith's RecoveryActivity takes Home until setupwraith is disabled.
# - Unlike the Chromecast, the remote's app buttons and mic keep working with launcherx disabled
#   (com.gretzky.GlobalKey handles them; keep it). No key-mapper workaround needed.
#
# Kept on purpose: Google Assistant (com.google.android.katniss), Cast receiver
# (com.google.android.apps.mediashell), onn update prompts (com.onn.updatenotification), com.gretzky.GlobalKey (onn remote app buttons), com.gretzky.hwinfo,
# com.droidlogic.* (Amlogic vendor: HDMI, picture, remote pairing), com.onn.bluetoothconnect,
# Play Store / Play Services, Gboard, com.google.android.tv.dfuservice (remote firmware updates),
# com.google.android.tv.remote.service (phone remote).
